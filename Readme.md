# ContractShield

## AI-Powered Smart Contract Security Auditor

ContractShield is an AI-powered platform that helps developers identify and fix security vulnerabilities in Solidity smart contracts before deployment.

The system combines **Slither**, a static analysis tool, with a **Large Language Model (LLM)** to detect vulnerabilities, explain them in simple language, assess their severity, and recommend secure coding practices.

## Features

- Analyze Solidity smart contracts
- Detect common vulnerabilities
- Generate AI-powered explanations
- Provide severity ratings
- Recommend fixes for each issue
- Produce downloadable security reports

## Technologies

- Solidity
- Python
- Slither
- OpenAI/LLM
- Git & GitHub
